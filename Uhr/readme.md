# Radzimmer Uhr designed in OpenSCAD

Die für den 3D-Druck benötigten STL-Dateien werden über das Skript ´create_stl.bat` automatisch generiert.
Dieses Skript lädt das OpenSCAD-Modell, rendert die einzelnen Komponenten und exportiert sie jeweils als separate STL-Dateien.

Alternativ liegen fertig gerenderte Dateien im Ordner stl.

Anschließend können beide erzeugten STL-Dateien (Datei A und Datei B) im 3D-Druckprogramm gemeinsam importiert werden. 
Achte darauf, dass sie als ein zusammengehöriges Objekt geladen werden, damit ihre Positionierung zueinander exakt erhalten bleibt.
Nach dem Import lassen sich die beiden Modellteile unterschiedlichen Farben zuordnen.
